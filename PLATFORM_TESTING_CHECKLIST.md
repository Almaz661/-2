# 🧪 Чек-лист проверки и тестирования приложения на других платформах

Этот документ предназначен для системной проверки работоспособности приложения **«Дом без хаоса»** после его развертывания на любом целевом окружении: десктопах (macOS, Windows, Linux), смартфонах (iOS, Android), планшетах (iPad, Samsung Tab) и в различных браузерах.

## 🔍 2. Чек-лист проверки базового развертывания и инфраструктуры

- [ ] **HTTP статус и загрузка:** Главная страница отдает код `200 OK`, HTML содержит корректные мета-теги `title` («Дом без хаоса — Семейный органайзер») и `theme-color`.
- [ ] **Консоль браузера (DevTools Console):** Отсутствуют критические ошибки (`Uncaught ReferenceError`, `SyntaxError`, бесконечные циклы).
- [ ] **Проверка сборки статики:** Все CSS (Tailwind) и JS-чанки загружаются без ошибок 404.
- [ ] **Серверные API маршруты:**
  - `GET /api/detect-location` возвращает JSON с координатами и городом по IP.
  - `POST /api/family-sync/push` принимает и сохраняет состояние семьи.
  - `GET /api/family-sync/pull/:code` возвращает сохраненное состояние по коду.
- [ ] **Интеграция с Gemini API (при наличии ключа):**
  - При отправке чека или сложного голосового запроса сервер успешно обращается к Google Gen AI SDK.
  - При отсутствии ключа приложение **не падает**, а корректно переключается на встроенный Rule Engine.

## ⚡ 3. Чек-лист PWA, оффлайн-режима и локального хранилища

- [ ] **Регистрация Service Worker:**
  - Откройте *DevTools* -> вкладка *Application* -> *Service Workers*.
  - Статус: `Activated and is running`. Файл: `sw.js` (генерируется Workbox).
- [ ] **Проверка Web App Manifest:**
  - В *DevTools* -> *Application* -> *Manifest* отображаются:
    - Имя: «Дом без хаоса — Семейный органайзер»
    - Короткое имя: «ДомБезХаоса»
    - Иконки: 192x192, 512x512, maskable 512x512
    - Цвет темы: `#E15A42`
    - Display mode: `standalone`
- [ ] **Тестирование оффлайн-режима (Network: Offline):**
  1. В DevTools на вкладке *Network* переключите пресет скорости на **Offline** (или включите «Авиарежим» на телефоне).
  2. Обновите страницу (Ctrl+R / Cmd+R).
  3. **Ожидаемый результат:** Страница мгновенно загружается из кэша Service Worker. В шапке приложения появляется аккуратный бейдж «Оффлайн-режим (IndexedDB)».
  4. Создайте новую задачу или пункт в списке покупок.
  5. Перезагрузите страницу в оффлайне — данные сохранились в IndexedDB и отображаются на экране.
- [ ] **Проверка баз данных IndexedDB:**
  - В *DevTools* -> *Application* -> *IndexedDB* присутствуют хранилища:
    - `onehaus_offline_db` (хранилища `tasks-store`, `events-store`)
    - `onehaus_receipt_photos_db` (хранилище `receipt-photos-store`)

## 📲 4. Чек-лист проверки на мобильных устройствах (iOS и Android)

### iOS (Safari):
- [ ] Нажмите кнопку «Поделиться» (Share) -> **«На экран «Домой»» (Add to Home Screen)**.
- [ ] На рабочем столе появляется иконка с красивым логотипом и названием.
- [ ] Запустите приложение с иконки: открывается в режиме **Standalone** (без адресной строки браузера и лишних рамок Safari).
- [ ] Проверьте нижнюю навигацию (**BottomNav**): плавная смена вкладок, удобный размер зон нажатия под большой палец.
- [ ] Проверьте статус-бар (SafeArea) сверху и снизу: контент не перекрывается вырезом камеры (Dynamic Island / Notch) и полосой жестов «Home Indicator».

### Android (Chrome):
- [ ] При первом входе появляется всплывающая подсказка / кнопка «Установить приложение».
- [ ] Установка в виде автономного PWA-приложения в лаунчер Android.
- [ ] Запуск из списка приложений: чистый нативный интерфейс во весь экран.

## 🧩 5. Функциональное тестирование модулей приложения

### 5.1. Главный обзор (Dashboard)
- [ ] Отображается приветствие, текущая дата на русском языке.
- [ ] Виджет погоды: показывает текущую температуру, ощущается как, прогноз на день. При клике можно вручную выбрать город или страну.
- [ ] Карточки быстрого доступа: «Дела на сегодня», «Ближайшие события», «Срочные покупки», «Контроль сроков аптечки».

### 5.2. Задачи и рутины (Tasks)
- [ ] Создание задачи вручную: название, выбор зоны (Кухня, Ванная и др.), выбор исполнителя, дата, баллы.
- [ ] Ротация: включение переключателя «Ротация между членами семьи».
- [ ] Применение пакета задач (**Task Packs**): выберите пакет «Генеральная уборка» или «Отпуск» -> все задачи пакета добавляются в список.
- [ ] Фильтрация задач: вкладки «Все», «Мои», по зонам, по статусу выполнения.
- [ ] Отметка выполнения: клик по чекбоксу — задача зачеркивается, начисляются баллы в профиль участника.

### 5.3. Семейный календарь (Calendar)
- [ ] Переключение видов: «Месяц», «Неделя», «Список».
- [ ] Создание события с выбором времени, категории и участников.
- [ ] Экспорт календаря: кнопка **«Экспорт в .ics»** — скачивается валидный файл `family-calendar.ics`, который можно открыть в Apple Calendar или Google Calendar.

### 5.4. Списки покупок (Shopping)
- [ ] Переключение между списками («Супермаркет», «Аптека», «Строительный»).
- [ ] **Smart Bulk Add (Умный списочный ввод):**
  - Откройте модальное окно быстрого добавления.
  - Вставьте текст:
    ```
    Молоко 3.2% 2 шт
    Хлеб бородинский
    Бананы 1.5 кг
    Стиральный порошок 1 уп
    Сыр чеддер
    ```
  - Нажмите «Добавить». Все 5 товаров должны автоматически распределиться по категориям (*Молочные*, *Выпечка*, *Овощи и фрукты*, *Бытовая химия*).
- [ ] Зачеркивание купленного товара кликом.
- [ ] Очистка выполненных позиций кнопкой «Очистить купленное».

### 5.5. Сканер кассовых чеков и OCR (Receipts)
- [ ] **Тест с камерой / файлом:**
  - Нажмите «Сканировать чек».
  - Выберите файл фото чека или сделайте снимок с камеры смартфона.
- [ ] **Проверка распознавания:**
  - Если настроен Gemini API: чек распознается с мультимодальной точностью (магазин, дата, все товары с ценами, налог BTW/НДС, финальная сумма).
  - Если Gemini API выключен/оффлайн: включается локальный OCR Tesseract.js прямо в браузере.
- [ ] **Проверка сверки и добавления:**
  - В окне сверки чека проверьте возможность скорректировать цены или категории.
  - Нажмите «Импортировать товары в список покупок» — товары попадают в список покупок.
- [ ] **Графики расходов:**
  - Проверьте отображение ежемесячного графика расходов и круговой диаграммы распределения затрат по категориям.

### 5.6. Питание и рецепты (Meals & Recipes)
- [ ] Недельный план: просмотр распределения блюд с понедельника по воскресенье.
- [ ] Назначение рецепта на конкретный день и прием пищи.
- [ ] **Импорт рецепта из интернета:**
  - Нажмите «Импорт по ссылке».
  - Вставьте ссылку на кулинарный сайт или YouTube-видео с рецептом.
  - Нажмите «Распознать через AI».
  - Проверьте, что извлечены фото блюда, список ингредиентов с граммовками и пошаговые инструкции.
- [ ] Кнопка **«Добавить ингредиенты в покупки»** — все продукты из рецепта попадают в список «Супермаркет» отдельными пунктами.

### 5.7. Домашняя аптечка (First Aid)
- [ ] Добавление лекарства: название, форма выпуска, срок годности, место хранения, показания.
- [ ] Проверка фильтра по срокам: «Истекающие», «Просроченные», «В норме».
- [ ] Бейджи сроков: красная плашка для просроченных препаратов, оранжевая для тех, у которых срок кончается в ближайшие недели.

### 5.8. Счётчики ЖКХ (Utilities)
- [ ] Просмотр счетчиков (Холодная вода, Горячая вода, Электричество, Газ).
- [ ] Ввод показаний за текущий месяц.
- [ ] Проверка авторасчета: разница с предыдущим месяцем корректно умножается на тариф и выводится итоговая сумма к оплате.

### 5.9. Экстренный режим SOS
- [ ] Клик по красной кнопке **SOS** в шапке или сайдбаре:
  - Модальное окно открывается мгновенно, без задержек.
  - Доступны кнопки прямого вызова (112, Скорая, Полиция, Пожарные) с интерактивным вызовом на телефоне (`tel:112`).
  - Отображаются вкладки первой помощи при ожогах, порезах, обмороке.
  - Отображаются карточки здоровья семьи (аллергии, группа крови).

### 5.10. Умный ввод «Send it in»
- [ ] Нажмите на кнопку со звездочкой/микрофоном.
- [ ] **Текстовый тест:**
  - Введите: `Купить яблоки 1 кг и йогурт завтра`
  - Результат: распознано 2 позиции в список покупок.
- [ ] **Голосовой тест (при поддержке Web Speech API в браузере):**
  - Нажмите на иконку микрофона, произнесите фразу.
  - Текст распознается и конвертируется в действия.

### 5.11. Семейная синхронизация и резервные копии (Settings)
- [ ] В разделе **Настройки** -> **Синхронизация семьи**:
  - Нажмите «Создать код семьи» (например, сгенерируется `HAUS-1234`).
  - На втором устройстве/в режиме инкогнито откройте приложение и нажмите «Подключиться к семье» с этим кодом.
  - Измените задачу на первом устройстве — на втором устройстве обновите данные: изменения синхронизируются.
- [ ] **Резервная копия (JSON Backup):**
  - Нажмите «Экспорт всех данных» — скачивается файл `onehaus-backup-*.json`.
  - Очистите данные или откройте новый браузер -> нажмите «Импорт из бэкапа» -> все данные семьи восстанавливаются в исходном виде.

## 🎯 6. Проверка производительности и метрик (Lighthouse)

Рекомендуется запустить аудит Google Chrome Lighthouse (F12 -> вкладка Lighthouse):
- **Performance:** >= 90 (быстрая начальная отрисовка без блокирующих тяжелых библиотек).
- **Accessibility:** >= 95 (высокая контрастность, читаемые шрифты, поддержка screen reader).
- **Best Practices:** >= 95 (HTTPS, отсутствие устаревших API).
- **PWA:** Соответствие всем критериям прогрессивного веб-приложения (манифест, сервис-воркер, иконки).
