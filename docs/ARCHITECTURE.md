## 1. Что это за приложение

Семейная платформа-помощник по дому: одна база знаний о доме, людях, вещах и обязанностях и активный ассистент, который напоминает, связывает данные и предлагает следующий шаг. Данные вводятся один раз — сроки, задачи, покупки и экстренная информация появляются сами.

**Принципы, которые соблюдаются в коде**

| Принцип | Как реализован |
|---|---|
| Данные вводятся один раз | Одна общая модель данных (`HouseholdContext`), разделы читают её, а не копируют |
| Ассистент предлагает, человек подтверждает | Автодействия ассистента — один раз на событие, с журналом; голос и умный ввод показывают, что поняли, до сохранения |
| Приложение не создаёт лишней работы | Без «Что я забыла?»; запасы — одно касание; профиль дома — один раз |
| До 2 часов в день без готовки, лёгкие выходные | План уборки по «Расписанию домашних дел v2», автотесты на лимиты |
| Один день — одна часть дома | Уборка по комнатам и приборам, полы в конце |
| Японский дизайн, без иероглифов | Палитра васи/сумі/ай-иро, шрифт Noto Serif для заголовков; иероглифов в коде нет |
| Основное работает без интернета | Данные хранятся на устройстве; без сети работают все разделы, кроме ИИ, распознавания фото, погоды, фото из интернета и курса валют (подробно — раздел 1.1) |

### 1.1. Что работает без интернета

Приложение поддерживает **частичный автономный режим**: всё, что хранится на устройстве, доступно без сети; сервисы из интернета — нет.

| Работает без интернета | Нужен интернет |
|---|---|
| Сегодня, задачи, календарь, план уборки, чек-листы, библиотека | Умный ввод через ИИ Gemini (без сети — разбор фраз на устройстве, попроще) |
| Покупки, запасы, режим «В магазине» | Распознавание чеков (ИИ Gemini и загрузка модуля tesseract) |
| Аптечка, счётчики, инвентарь, техосмотр, паспорт дома | Голосовой ввод (зависит от браузера, часто использует сервер браузера) |
| SOS: памятки, где что отключается, фото мест отключения | Погода, фото Unsplash, шрифты Google (без сети — системные), курс валют (без сети — последний сохранённый) |
| Профиль дома, настройки, семейный экран | Семейная синхронизация |

### 2.1. Главный ассистент (оркестратор)

| Файл | Что делает |
|---|---|
| `src/services/orchestrator.ts` | Чистые правила без побочных эффектов: собирает «сигналы» из документов, аптечки, имущества, счётчиков, задач и календаря; для части сигналов предлагает действие (создать задачу, добавить в покупки) |
| `src/components/assistant/AssistantEngine.tsx` | Невидимый «мотор»: при изменении данных и раз в 30 минут выполняет действия (каждое — один раз, по ключу), возвращает в работу повторяющиеся дела, шлёт уведомления раз в день и утреннее сообщение |
| `src/components/assistant/useAssistant.ts` | Настройки, журнал «Что ассистент сделал сам», отметки выполненного |
| `src/services/cleaningPlan.ts` | План по дням и на год: темы дней v2, уборка по частям дома, равномерное распределение редких дел, лимит времени |
| `src/utils/cleaningOrder.ts` | Порядок внутри дня: по комнатам, затем по прибору или месту; полы в конце |
| `src/services/aiService.ts`, `smartInputRouter.ts`, `src/utils/ruDate.ts` | Разбор фраз «напомнить мне 5 декабря…», «купить молоко и хлеб», «в аптечку…» на устройстве; с ключом Gemini — через сервер |

**Правила ассистента**

| Ситуация | Что делает сам |
|---|---|
| Документ истекает в течение 14 дней | Задача «Продлить: …» (для гарантий — только напоминание) |
| Лекарство заканчивается или просрочено | В список «Аптека» |
| ТО, страховка, обслуживание, прививка | Задача: срочное — сегодня, плановое — в ближайший понедельник (день планирования) |
| 15–25 число, нет показаний счётчиков | Задача «Передать показания» |
| Повторяющееся дело снова «пора» | Возвращает в работу с новым сроком |
| Горящие сроки | Системное уведомление раз в день |
| Каждое утро (по умолчанию 08:00) | Сообщение с задачей дня |

### 2.2. Доменные агенты → модули приложения

**Важно о словах.** «Агент» в архитектуре проекта — это **зона ответственности**, а не отдельный ИИ. В коде каждый агент — обычный программный модуль (экраны, данные, правила). Искусственный интеллект (Gemini) используется только в четырёх местах: умный ввод, расшифровка голоса, распознавание чеков, импорт рецептов. Главный ассистент работает **по правилам** (`orchestrator.ts`), без ИИ — поэтому его действия предсказуемы и записываются в журнал.

| Агент по архитектуре | Где в приложении | Основные файлы | Статус |
|---|---|---|---|
| Дом и объекты | Профиль дома, Паспорт дома, объекты в шапке | `home/HomeProfileForm.tsx`, `inventory/HomePassport.tsx`, `utils/homeProfile.ts` | Работает |
| Задачи и календарь | Задачи (Дела, Уборка, Чек-листы, Библиотека), Календарь (Месяц, Неделя, Список, Уборка) | `tasks/*`, `calendar/*`, `data/catalog.ts`, `data/homeRoutine.ts`, `data/cleaningMap.ts` | Работает |
| Покупки и запасы | Покупки (Списки, Запасы, Чеки), режим «В магазине» | `shopping/*`, `receipts/*`, `utils/shoppingParser.ts`, `data/supplies.ts` | Работает |
| Документы и сроки | Документы (раздел скрыт по умолчанию), Паспорт дома → Документы | `docs/*`, `inventory/HomePassport.tsx` | Работает |
| Люди, роли, доступ | Настройки → Члены семьи, фильтр «Участник» | `settings/SettingsView.tsx` | Частично: ролей и прав доступа ещё нет |
| SOS и безопасность | SOS: экстренные службы, «Что делать, если…», где что отключается (с фото), семья, ДТП, мед. и питомцы | `sos/*` | Работает |
| Обслуживание, техника, транспорт | Инвентарь, Техосмотр дома, Обслуживание техники | `inventory/*`, `data/techCheck.ts` | Работает |
| Здоровье, аптечка, питомцы | Аптечка, карточки питомцев в Инвентаре, SOS | `firstaid/*` | Работает |
| Финансы и подписки | Чеки и расходы, начисления ЖКХ, подписки в Инвентаре | `receipts/*`, `utilities/*` | Частично: бюджета и регулярных платежей нет |
| Сезонный дом (дача, сад, гардероб) | Сезонные чек-листы, сезонность интерфейса | `tasks/ChecklistsBoard.tsx`, `utils/season.ts` | Работает |
| Поездки, соцжизнь, подарки | Чек-листы по событию: гости, поездка, праздник | `data/initialData.ts` (наборы `pack-ev-*`) | Частично |

### 3.3. Где хранятся данные: три разных механизма

| Механизм | Где | Когда | Что |
|---|---|---|---|
| **1. Локальное хранение** | Память браузера на устройстве (localStorage) и офлайн-база (IndexedDB) | Всегда, автоматически | Все данные приложения |
| **2. Семейная синхронизация** | Сервер приложения, файл `data/families/<код>.json` | Только если включить и ввести код семьи | Копия всего состояния семьи для другого устройства |
| **3. Резервная копия** | Файл JSON у вас («Настройки» → «Данные» → «Экспорт в JSON», обратно — «Импорт из JSON») | Вручную, когда нажмёте | Все данные приложения |

**Офлайн-база IndexedDB** — дополнительная копия задач и событий для надёжности. Остальные разделы (покупки, рецепты, лекарства, документы, инвентарь, чеки, запасы, паспорт) хранятся в localStorage — и **тоже полностью доступны без интернета**.

**Предел памяти браузера** зависит от браузера и устройства (часто около 5 МБ на сайт, у Safari — свои правила). Больше всего места занимают фото чеков. С версии 1.1 при переполнении приложение **показывает предупреждение** и предлагает сделать резервную копию.

| Хранилище | Ключи | Что |
|---|---|---|
| localStorage `onehaus_v4_*` | `tasks`, `events`, `shopping_lists`, `shopping_items`, `recipes`, `meal_plan`, `inventory`, `docs`, `contacts`, `scanned_receipts`, `medicines`, `utility_meters`, `properties`, `active_property_id`, `members`, `household_*`, `pet_emergency`, `accident_guidance`, `medical_emergency`, `family_code`, `last_cloud_sync` | Основная модель дома |
| localStorage `dbh_*` | `dbh_home_profile`, `dbh_supplies`, `dbh_cleanmap`, `dbh_routine_*`, `dbh_routine_custom`, `dbh_techcheck`, `dbh_passport_<объект>`, `dbh_shutoff_<объект>_<что>`, `dbh_library_hidden`, `dbh_assistant*`, `dbh_theme`, `dbh_photo_*`, `dbh_welcome_seen`, `dbh_tour_seen` | Новые модули и настройки |
| IndexedDB `onehaus_offline_db` | задачи, события | Офлайн-копия |
| Сервер `data/families/<код>.json` | всё состояние семьи | Только при семейной синхронизации |

## 4. Разделы и как они работают

| Раздел | Вкладки и возможности |
|---|---|
| **Сегодня** | Фото с приветствием и сезоном; **погода на сегодня** (сейчас, день и ночь, дождь, ветер, по часам, совет по дому);  события дня; «Задача дня» с планом по комнатам; дела на сегодня; тихая строка «Не на сегодня, но ждёт»; «Дом» — 4 зоны карты уборки; ужин и покупки |
| **Задачи** | Дела (по дате, внутри дня — по комнатам); Уборка (карта уборки по схеме 4×3); Чек-листы (ежедневный график v2 с настройкой, неделя, месяц, по событию, по сезону); Библиотека (430 дел, «В дела», «Не про нас») |
| **Календарь** | Месяц, Неделя, Список, Уборка (план на месяц и год); праздники; экспорт в Apple/Google; на телефоне — ближайшие 7 дней |
| **Покупки** | Списки (по отделам в порядке магазина, правка товара, переименование и удаление списков, «В магазине»); Запасы (есть → заканчивается → нет, само в покупки); Чеки (распознавание, графики, **расходы по товарам за месяц**, пересчёт в рубли) |
| **Питание** | План на неделю, рецепты, импорт рецепта |
| **Аптечка** | Лекарства, сроки, «заканчивается» → в покупки |
| **Счётчики ЖКХ** | Показания, начисления по тарифам, графики, текст для УК |
| **Инвентарь** | Имущество; Техосмотр дома; Паспорт дома |
| **Настройки** | Дом и семья (профиль дома, страна и валюта, члены семьи); Ассистент; Вид и меню; Данные (синхронизация, офлайн, резервная копия, сброс) |
| **SOS** | Без пароля: службы, «Что делать, если…» (газ, угарный газ, протечка, свет, искрит, нет отопления), где что отключается с фото, семья, ДТП, медицина, питомцы |
| **Семейный экран** | Режим для iPad на подставке: часы, день, дела, ужин, покупки; экран не гаснет |
| **Умный ввод** | Текст, голос, фото чека; понимает русские, нидерландские и английские даты |

### 4.1. Чеки: от фото до расходов

| Шаг | Как сделано | Без интернета |
|---|---|---|
| 1. Фото или файл чека | Камера или галерея, проверка качества фото | Да |
| 2. Распознавание | ИИ Gemini: языки чека — русский, нидерландский, немецкий, польский, греческий, английский и другие. Запасной путь — tesseract.js на устройстве | Нет (модуль tesseract грузится из интернета) |
| 3. Перевод на русский | У каждой строки два текста: с чека (`originalText`) и понятное название на русском (`normalizedTitle`) | Только с ИИ |
| 4. Категории товаров | Продукты, бытовая химия, аптека и т. д. (`category`) | Только с ИИ |
| 5. Проверка | Строки с низкой уверенностью помечаются «проверить», сверка суммы строк с итогом чека | Да |
| 6. Аналитика | Расходы по месяцам и категориям; **расходы по каждому товару за месяц**: сколько раз, сколько потрачено, последняя цена и рост или снижение к прошлой покупке | Да |
| 7. Курс валют | Пересчёт в рубли: 1 € = … ₽ (ExchangeRate-API, запасной источник — ЦБ РФ), кэш на сутки | Последний сохранённый курс |

Сравнение цен в разных магазинах **не делается** — по решению владельца.

### 4.2. Уведомления

| Что | Как работает |
|---|---|
| Утреннее сообщение | Один раз в день, в выбранное время (по умолчанию 08:00), по местному времени устройства |
| Горящие сроки | Не чаще одного раза в день на каждый срок |
| Повторы и дубли | Отметка «уже отправлено сегодня» хранится на устройстве — повторов нет |
| Разрешение | Спрашивается в «Настройки» → «Ассистент»; без разрешения сообщение видно только в приложении |
| Приложение закрыто | Не приходят — нужен сервер push-уведомлений (этап 4) |

## 5. Сервер и подключённые программы

### 5.1. Сервер `server.ts` (Express)

| Адрес | Что делает |
|---|---|
| `POST /api/ai/parse` | Разбор фразы умного ввода через Gemini; без ключа отвечает 503, и приложение разбирает на устройстве |
| `POST /api/ai/transcribe` | Расшифровка голоса |
| `POST /api/ai/parse-receipt` | Распознавание чека |
| `POST /api/ai/import-recipe` | Импорт рецепта по ссылке или тексту |
| `GET /api/detect-location` | Город по IP |
| `POST /api/family-sync/push`, `GET …/pull/:code`, `GET …/check/:code` | Семейная синхронизация через файлы на сервере |

**Переменные окружения:** `GEMINI_API_KEY`, `PORT`, `NODE_ENV`.
**Модели ИИ в коде:** `gemini-3.8-flash`, `gemini-3.5-flash`, `gemini-3.1-flash-lite`, `gemini-3.5-transcribe`.

### 5.2. Внешние сервисы

## 9.1. Безопасность и личные данные — план этапа 3

| Что | Как будет сделано |
|---|---|
| Отдельные аккаунты | Вход по ссылке на почту (Supabase Auth), у каждого члена семьи свой аккаунт |
| Права доступа | Правила на уровне базы (Row Level Security): видит только своя семья; роли Ольга — владелец, Сергей — общие задачи, календарь и покупки, семья — назначенное, мастера — только свои задачи; права по объектам (квартира, дача) |
| Хранение на сервере | База PostgreSQL в Supabase вместо файлов JSON |
| Шифрование | Передача — только HTTPS; хранение — шифрование диска у Supabase; самые чувствительные поля (документы, медицина) — дополнительное шифрование на устройстве перед отправкой |
| Резервные копии | Ежедневные копии базы (тариф Pro — хранятся 7 дней) + автоматический еженедельный экспорт JSON на устройство |
| Переход | Текущие данные с устройства переносятся в аккаунт при первом входе; без входа приложение продолжает работать локально |

### 9.2. GDPR и правила хранения данных

- **Для своей семьи** GDPR не применяется: обработка в личных и домашних целях из него исключена.
- **Если давать приложение другим людям**, понадобятся: политика конфиденциальности, согласие на обработку, удаление аккаунта и всех данных по запросу, выгрузка своих данных, договор об обработке данных с Supabase и Google, хранение в ЕС.
- **Сейчас:** все данные на устройстве; удаление — «Настройки» → «Данные» → сброс; на сервере — только файл синхронизации семьи, если её включали.
