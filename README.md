# 🏡 Дом без хаоса — Семейный органайзер и центр управления домом

> **Полноценный русскоязычный PWA-центр управления домом и семейный органайзер:** задачи и ротация обязанностей, общий семейный календарь, умные списки покупок, сканер и OCR кассовых чеков, недельный план питания и кулинарная книга, домашняя аптечка со сроками годности, счётчики ЖКХ, учёт имущества, архив документов, база проверенных мастеров, экстренный режим SOS, голосовой/интеллектуальный ввод «Send it in» и оффлайн-работа.

## ✨ Ключевые возможности

### 1. 🧹 Задачи и рутины (Tasks & Routines)
- **Ротация обязанностей:** автосмена ответственных (например, мытьё посуды чередуется между членами семьи).
- **Пакеты готовых задач (Task Packs):** моментальное применение списков («Генеральная уборка», «Подготовка к зиме», «Переезд», «Приём гостей», «Отпуск»).
- **Зонирование дома:** разделение по комнатам (Кухня, Ванная, Детская, Авто, Гостиная, Весь дом).
- **Геймификация и баллы:** начисление очков за выполнение поручений для мотивации детей и подростков.

### 2. 📅 Семейный календарь (Family Calendar)
- Единое расписание всех членов семьи с цветными аватарами и бейджами.
- Категории событий: «Семья», «Дети», «Здоровье и врачи», «Дом и мастера», «Работа».
- Экспорт в формат `.ics` для подключения к Apple Calendar, Google Calendar, Outlook.

### 3. 🛒 Списки покупок (Smart Shopping)
- Мульти-списки: «Супермаркет», «Аптека», «Строительный маркет», «Детские товары» и др.
- Автоматическая категоризация товаров по 10 группам (овощи/фрукты, молочка, мясо, бакалея, бытовая химия и т.д.).
- **Smart Bulk Add:** добавление нескольких позиций одной строкой («молоко 2л, хлеб, сыр, помидоры 1 кг»).
- Импорт ингредиентов из любого рецепта в список покупок в 1 клик.

### 4. 🧾 Сканер и распознавание кассовых чеков (Receipt Scanner & OCR)
- **Гибридный движок распознавания:**
  - **Локальный OCR (Tesseract.js):** выполняется прямо в браузере на устройстве, работает 100% оффлайн без интернета.
  - **Интеллектуальное зрение Gemini Vision:** серверный анализ фото чека с каскадом моделей (`gemini-3.8-flash`, `gemini-3.1-flash-lite`). Идеально извлекает названия товаров, цены, скидки, НДС, валюту и дату.
- Поддержка чеков из любых стран: Россия, Нидерланды (Albert Heijn, Jumbo, Lidl), Германия (REWE, ALDI, Edeka), Греция (Sklavenitis, AB Vassilopoulos), Польша (Biedronka), Франция, США и др.
- Автоматическая конвертация позиций чека в список покупок или учёт расходов.
- Аналитические графики расходов по месяцам и круговая диаграмма распределения трат по категориям.
- Сохранение фотографий чеков в клиентскую базу **IndexedDB** (не перегружает лимит LocalStorage).

### 5. 🍲 Питание и семейные рецепты (Meal Planning & Recipes)
- Недельный планировщик меню на 7 дней (Завтрак, Обед, Ужин, Перекус).
- Кулинарная книга с поиском по ингредиентам, тегам, времени приготовления и калориям.
- **Умный импорт рецептов по ссылке:** вставьте ссылку на кулинарный сайт, YouTube видео или скопированный текст — система автоматически извлечет фото, ингредиенты с граммовками и пошаговые инструкции через Gemini API.
- Мгновенная отправка недостающих ингредиентов в список покупок.

### 6. 💊 Домашняя аптечка (First Aid & Medicines)
- Учёт лекарств дома с привязкой к аптечкам/местам хранения.
- Автоматический мониторинг сроков годности с цветовой индикацией: «Просрочено», «Истекает в ближайшие 30 дней», «Истекает через 90 дней», «В норме».
- Фиксация дозировок, действующих веществ, назначения и правил приёма.

### 7. ⚡ Счётчики ЖКХ и коммуналка (Utilities & Meters)
- Учёт показаний счетчиков: холодная и горячая вода, электроэнергия (однотарифный, день/ночь, пик/полупик/ночь), газ, отопление.
- Ввод показаний за текущий месяц, автоматический расчёт дельты расхода и стоимости по настраиваемым тарифам.
- Графики динамики потребления ресурсов по месяцам.

### 8. 📦 Инвентарь и имущество (Home Inventory)
- Карточки бытовой техники, электроники, мебели, автомобилей и домашних животных.
- Контроль окончания гарантийных сроков, сервисных интервалов, серийных номеров и привязанных документов/чеков.

### 9. 📁 Документы дома (House Documents)
- Учёт паспортов, свидетельств, страховых полисов (ОСАГО, КАСКО, ДМС, недвижимость), договоров аренды.
- Заблаговременные напоминания об истечении срока действия документов.

### 10. 📞 База контактов и мастеров (Contacts & Pros)
- Проверенные сантехники, электрики, управляющая компания, клининг, семейный врач, ветеринар.
- Кнопки быстрого звонка в один клик.

### 11. 🚨 Экстренный режим SOS
- Открывается мгновенно в 1 клик с любого экрана без паролей.
- Телефоны экстренных служб с автоопределением страны (112, скорая, полиция, пожарные, газовая служба).
- Интерактивные памятки первой помощи (ожоги, кровотечения, отравления, удар током, переохлаждение, СЛР).
- Карточки экстренной медпомощи членов семьи (группы крови, аллергии, хронические диагнозы) и ветеринарные данные питомцев.

### 12. 🎙️ Умный ввод «Send it in» (AI & Голос)
- Ввод текста свободной фразой или голосом через микрофон:
  - *"Купить огурцы 1 кг, сметану и средство для мытья посуды"* ➔ создаст 3 позиции в списке покупок в правильных категориях.
  - *"В субботу в 11:00 приём у педиатра с сыном"* ➔ создаст событие в календаре с напоминанием.
  - *"Помыть духовку на кухне до завтра"* ➔ создаст задачу с нужной зоной и сроком.
- Двухуровневый движок: при наличии ключа Gemini работает нейросеть; при отсутствии или оффлайн — моментально отрабатывает локальный Rule Engine.

### 13. 🔄 Семейная облачная синхронизация
- Простое объединение нескольких устройств членов семьи по 6-значному коду домохозяйства (например, `HAUS-4921`).
- Без сложных паролей и регистрации: синхронизация происходит через серверные endpoints `/api/family-sync/*`.
- Возможность экспорта и импорта полного резервного JSON-файла домохозяйства.

## 🛠️ Технологический стек

- **Frontend:** React 19, TypeScript, Vite 8, Tailwind CSS v4, Lucide React (иконки), Recharts (графики), Motion (анимации).
- **Backend / API:** Node.js, Express, tsx.
- **AI & Computer Vision:** `@google/genai` (Google Gen AI SDK v2.4.0) — модели `gemini-3.8-flash`, `gemini-3.1-flash-lite`.
- **OCR:** `tesseract.js` v7.0.0 (автономное распознавание текста на стороне браузера).
- **Offline & Storage:** IndexedDB (для задач, календаря и тяжелых фото чеков), LocalStorage (для быстрых настроек и состояний), Service Worker (Vite PWA / Workbox).
- **Погода:** Open-Meteo API с оффлайн-кэшированием и автоматическим определением локации по IP.

## 🚀 Быстрый старт (локальный запуск)

### Требования
- **Node.js:** версия 20.x или 22.x LTS (рекомендуется)
- **Менеджер пакетов:** `npm` (или `bun` / `pnpm` / `yarn`)

### Шаги установки:

1. **Клонируйте репозиторий:**
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd <ПАПКА_ПРОЕКТА>
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Настройте переменные окружения:**
   Скопируйте файл примера конфигурации:
   ```bash
   cp .env.example .env
   ```
   Откройте `.env` и при необходимости укажите ваш ключ Gemini API:
   ```ini
   GEMINI_API_KEY=AIzaSy...ваш_ключ
   PORT=3000
   ```
   *(Примечание: приложение полностью работает и БЕЗ ключа API — в оффлайн/эвристическом режиме).*

4. **Запустите сервер разработки:**
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу: **http://localhost:3000** (или на порту, указанном в переменной `PORT`).

5. **Сборка для Production:**
   ```bash
   npm run build
   npm start
   ```

## 🔒 Безопасность, аудит и конфиденциальность

- **Защита семейного кода от брутфорса:** Сервер блокирует IP-адрес на 15 минут при 8 последовательных ошибках ввода кода семьи.
- **Ограничение частоты запросов (Rate Limiting):** Защита от перегрузки и расхода квот API (максимум 30 вызовов AI в минуту на IP).
- **Изоляция секретов:** Ключ `GEMINI_API_KEY` используется исключительно на стороне Node.js сервера и гарантированно не попадает в клиентский бандл браузера.
- **Локальный приоритет (Local-First):** Все персональные данные семьи, документы, заметки и списки хранятся локально в браузере пользователя (`IndexedDB` и `LocalStorage`).
- **Юридические и медицинские дисклеймеры:** В модулях SOS и «Домашняя аптечка» закреплены предупреждения о необходимости обращения в экстренные службы (112) и к лечащим врачам.
- **Очистка логов (PII Sanitization):** Серверные логи не содержат персональных данных, фото и содержимого чеков.
- **Подробный отчёт аудита:** 👉 **[Ознакомиться с полным отчётом аудита (AUDIT_REPORT.md)](./AUDIT_REPORT.md)**
